# 能力画像维度动态化设计方案

## 一、设计思路

### 核心流程
```
用户确定AI模拟角色 → AI生成5个考核维度 → 用户确认 → AI生成评估提示词 → 保存到数据库
```

### 设计原则
1. **AI驱动生成**：根据角色自动生成维度，减少用户配置成本
2. **用户确认机制**：维度需用户确认，保证可控性
3. **提示词自动生成**：提示词无需确认，由AI自动完成
4. **JSON结构存储**：维度配置和提示词统一存储，便于扩展

### 2.2 交互流程设计

#### 步骤1：用户确定AI模拟角色
用户在场景创建时，通过对话方式描述AI需要模拟的角色：
- 行业：教育、金融、零售等
- 角色类型：客户、家长、学生、患者等
- 角色特征：性格、需求、痛点等

#### 步骤2：AI生成考核维度
根据角色信息，AI生成5个考核维度：

**维度生成提示词：**
```python

#### 步骤3：用户确认维度

- 确认接受

- 修改子项描述
- 重新生成

#### 步骤4：AI生成评估提示词
用户确认维度后，自动生成完整评估提示词：

**提示词生成逻辑：**
```python
def generate_full_evaluation_prompt(dimensions: List[DimensionConfig]) -> str:
    prompt = """你是一位资深培训评估专家，需要对培训对话进行专业评估。

## 评估维度

"""
    for dim in dimensions:
        prompt += f"### {dim.dimension_name} (权重: {dim.weight*100}%)\n"
        prompt += "评估要点：\n"
        for criterion, desc in dim.sub_criteria.items():
            prompt += f"- {criterion}：{desc}\n"
        prompt += "\n评分标准：\n"
        for level, desc in dim.score_levels.items():
            prompt += f"- {level}：{desc}\n"
        prompt += "\n"
    
    prompt += """## 输出格式
请严格按以下JSON格式返回评估结果...
"""
    return prompt
```

- 关联场景ID
- 支持后续修改

### 2.4 API接口设计

#### 新增接口
```python

  "scene_id": "scene_123",
  "dimension_config_id": "dc_456",

# 获取场景的维度配置

  "dimension_config": {...}
}

# 重新生成维度

```

## 五、风险与应对

| 风险 | 影响 | 应对措施 |
|-----|------|---------|
| AI生成维度质量不稳定 | 评估结果不准确 | 1. 优化提示词 2. 多次生成取最优 3. 预设模板兜底 |
| 相同角色生成不同维度 | 难以横向对比 | 1. 维度模板库复用 2. 支持维度标准化设置 |
| 用户不会调整维度 | 维度不合理 | 1. 提供维度建议 2. 智能权重调整 |
| 维度数量不固定 | 前端展示问题 | 1. 限制3-6个维度 2. 前端动态适配 |
