# 创建智能体能力设计分析与重构计划

## 一、设计方案对比分析

### 1.1 当前实现分析

**信息收集阶段：**
- 行业信息 (`industry`)
- AI扮演角色 (`ai_role`)
- 用户角色 (`role_type`)
- 角色描述 (`role_description`)
- 延展信息 (`extended_info`)
- 额外需求 (`additional_requirements`)

**内容生成阶段：**
| 生成内容 | 数量 | 描述 |
|---------|------|------|
| 背景信息 | 1段 | 200-500字的场景描述 |
| 主问题列表 | 3-5个 | 按对话顺序排列的核心问题 |
| 关联问题分组 | 2-4组 | 带触发关键词的问题组 |
| 考核维度 | 3-4个 | 带权重和子标准的评估维度 |
| 情绪画像 | 1个 | 情绪类型、描述、风格、态度 |

### 1.2 新设计方案分析

**信息收集阶段：**
| 信息项 | 说明 |
|--------|------|
| 行业 | 用户所在行业 |
| AI模拟的角色 | AI扮演的角色（如客户、访客等） |
| 被训练者的角色 | 用户扮演的角色（如销售、客服等） |

**内容生成阶段：**
| 生成内容 | 数量 | 描述 |
|---------|------|------|
| 背景信息 | 1段 | 基于行业和AI角色生成 |
| 必问问题 | 10个 | 对话过程中一定要提出的问题 |
| 可能问的问题 | 10个 | 对话过程中可能会提出的问题 |
| 考核维度 | 5个 | 每个维度包含考核提示词 |

### 1.3 核心差异对比

| 维度 | 当前实现 | 新设计方案 | 影响 |
|------|----------|------------|------|
| 信息收集 | 6项信息，较复杂 | 3项核心信息，简洁 | ⬇️ 简化交互流程 |
| 问题生成 | 主问题+关联问题（约10-15个） | 必问+可能问（固定20个） | ⬆️ 问题更全面 |
| 问题分类 | 按触发关键词分组 | 按必问/可能问分类 | ⬆️ 逻辑更清晰 |
| 考核维度 | 3-4个，有权重 | 5个，有考核提示词 | ⬆️ 评估更细致 |
| 情绪画像 | 有 | 未提及 | ❓ 待确认是否保留 |

## 二、新设计方案的优势

### 2.1 信息收集更简洁
- **减少用户负担**：从6项信息减少到3项核心信息
- **降低使用门槛**：用户无需提供过多细节即可开始
- **提高转化率**：简化的流程更容易让用户完成创建

### 2.2 问题生成更结构化
- **必问问题**：确保核心对话场景覆盖
- **可能问的问题**：增加对话的多样性和真实感
- **固定数量**：20个问题提供更充分的对话素材

### 2.3 考核维度更完善
- **5个维度**：比当前的3-4个更全面
- **考核提示词**：每个维度有明确的评估标准
- **针对性更强**：基于被训练者角色定制

   ```python
   industry, ai_role, trainee_role  # 更简洁
   ```

2. `MainQuestion` → 重构为 `RequiredQuestion`（必问问题）
   ```python
   @dataclass
   class RequiredQuestion:
       question: str
       order: int
   ```

3. 新增 `PossibleQuestion`（可能问的问题）
   ```python
   @dataclass
   class PossibleQuestion:
       question: str
       order: int
   ```

4. `TriggerGroup` - 可能需要移除或重构

5. `Dimension` - 增加 `assessment_prompt` 字段
   ```python
   @dataclass
   class Dimension:
       dimension_name: str
       weight: float
       sub_criteria: Dict[str, str]
       assessment_prompt: str  # 新增：考核提示词
   ```

6. `SceneContent` - 更新字段
   ```python
   @dataclass
   class SceneContent:

       ai_role: str
       trainee_role: str  # 新增：被训练者角色
   ```

### 3.2 提示词层 (`prompts.py`)

**需要修改的提示词：**

1. `SYSTEM_PROMPT` - 更新系统提示词
   - 简化信息收集流程
   - 明确3项核心信息

2. `INFO_EXTRACTION_PROMPT` - 更新信息提取提示词
   - 只提取行业、AI角色、被训练者角色

3. `CHAIN_OF_THOUGHT_QUESTIONS` → 重构为两个提示词：
   - `CHAIN_OF_THOUGHT_REQUIRED_QUESTIONS` - 生成10个必问问题
   - `CHAIN_OF_THOUGHT_POSSIBLE_QUESTIONS` - 生成10个可能问的问题

4. `CHAIN_OF_THOUGHT_TRIGGERS` - 可能移除

5. `CHAIN_OF_THOUGHT_DIMENSIONS` - 更新为生成5个维度+考核提示词

### 3.3 智能体逻辑层 (`agent.py`)

**需要修改的方法：**

1. `chat()` - 简化对话流程

   - 判断是否可以开始生成

2. `_extract_info()` - 更新信息提取逻辑

3. `_update_state()` - 更新状态更新逻辑

4. `generate_scene_content()` - 更新生成流程
   ```python
   def generate_scene_content(self) -> Optional[SceneContent]:
       # 1. 生成背景信息
       background_info = self._generate_background_info()
       
       # 2. 生成必问问题（10个）
       required_questions = self._generate_required_questions(background_info)
       
       # 3. 生成可能问的问题（10个）
       possible_questions = self._generate_possible_questions(background_info)
       
       # 4. 生成考核维度（5个+考核提示词）
       dimensions = self._generate_dimensions(background_info)
       
       # 5. 情绪画像（是否保留待确认）
       emotion_profile = self._generate_emotion_profile(background_info)
   ```

5. 新增方法：
   - `_generate_required_questions()` - 生成10个必问问题
   - `_generate_possible_questions()` - 生成10个可能问的问题

6. 移除方法：
   - `_generate_trigger_groups()` - 关联问题分组生成

7. `build_prompt()` - 更新提示词构建逻辑

## 七、总结

新设计方案相比当前实现有以下改进：
1. **更简洁**：信息收集从6项减少到3项
2. **更结构化**：问题分类更清晰（必问/可能问）
3. **更全面**：问题数量增加到20个
4. **更细致**：考核维度增加到5个，每个维度有考核提示词

建议采用渐进式重构策略，先完成核心功能，再逐步优化细节。
