# 角色定位错误问题分析与优化方案

## 🐛 问题描述

**用户反馈**：
- 用户明确说"模拟客户"
- 但生成的提示词第一句是："你是一名汽车行业的销售"
- **AI 扮演了销售，而不是客户**
- 系统定位：AI 应该扮演客户/访客，用户扮演销售进行对练

## 🔍 问题根因分析

### 1. 当前代码逻辑

#### 问题代码位置
**文件**: `agent/service/scene/agent.py`  
**函数**: `build_prompt()`  
**行号**: 486-547

```python
def build_prompt(self) -> str:
    """构建完整的场景提示词"""
    if not self.scene_content:
        return ""
    
    content = self.scene_content
    
    # ❌ 问题出在这里！
    prompt_parts = [
        "# 角色设定",
        f"你是一名{content.industry}行业的{content.role_type}。",
        "",
        "# 场景背景",
        content.background_info,
        ...
    ]
```

#### 数据来源
`content.role_type` 来自用户输入提取：
- 用户说："我想创建汽车销售培训，AI 模拟客户"
- 信息提取后：
  - `industry` = "汽车销售"
  - `role_type` = "销售顾问"（用户的角色）
  - `ai_role` = "客户"（AI 应该扮演的角色）← **但这个字段没有被使用！**

### 2. 数据流分析

```
用户输入 → 信息提取 → 场景内容 → 构建提示词
   ↓           ↓           ↓          ↓
"AI 模拟   industry=汽车   role_type=  "你是一名
 客户"      role_type=销   销售顾问    汽车销售
           售顾问        ai_role=     行业的销售
                       客户        顾问"
                       ↓
                  (被忽略了！)
```

### 3. 核心问题

**问题 1: `build_prompt` 不知道 AI 应该扮演什么角色**
- 只使用了 `role_type`（用户的角色）
- 没有使用 `ai_role`（AI 的角色）
- 默认假设 AI 扮演 `role_type`

**问题 2: 提示词模板设计缺陷**
查看提示词模板文件 `prompts.py`：

```python
# 所有模板都在生成"销售"相关的内容
CHAIN_OF_THOUGHT_BACKGROUND = """
基于以下信息生成场景背景:
- 行业：{industry}
- 角色类型：{role_type}  ← 这里也是用户的角色
- 角色描述：{role_description}
- 延展信息：{extended_info}
"""

# 没有区分"用户角色"和"AI 角色"
```

**问题 3: 场景内容生成时角色混淆**
```python
def generate_scene_content(self):
    # 生成背景信息
    background_prompt = CHAIN_OF_THOUGHT_BACKGROUND.format(
        industry=self.state.industry,
        role_type=self.state.role_type,  # ← 传入的是用户角色
        role_description=self.state.role_description,
        extended_info=self.state.get_extended_info_summary()
    )
    # AI 根据这个提示词，自然认为要生成"销售"的背景
```

build_prompt() → f"你是一名{industry}行业的{role_type}"
              → "你是一名汽车销售行业的销售顾问"

### 正确设计（应该的）

## 🎯 优化方案

### 方案 1: 最小改动（推荐）

**核心思路**: 在 `build_prompt` 中区分用户角色和 AI 角色

#### 修改点 1: `build_prompt` 函数
**文件**: `agent/service/scene/agent.py`

```python
def build_prompt(self) -> str:
    """构建完整的场景提示词"""
    if not self.scene_content:
        return ""
    
    content = self.scene_content
    
    # ✅ 关键修改：使用 ai_role 而不是 role_type
    # 确定 AI 应该扮演的角色
    ai_character = content.ai_role or content.role_type
    
    prompt_parts = [
        "# 角色设定",
        f"你是一名{content.industry}行业的{ai_character}。",
        "",
        "# 场景背景",
        content.background_info,
        ...
    ]
```

#### 修改点 2: 场景内容生成
**文件**: `agent/service/scene/agent.py`

```python
def generate_scene_content(self):
    # ✅ 关键修改：传入 ai_role
    background_prompt = CHAIN_OF_THOUGHT_BACKGROUND.format(
        industry=self.state.industry,
        ai_role=self.state.ai_role,  # ← 改为 ai_role
        role_description=self.state.role_description,
        extended_info=self.state.get_extended_info_summary()
    )
```

#### 修改点 3: 提示词模板
**文件**: `agent/service/scene/prompts.py`

```python
# ✅ 修改模板，使用 ai_role
CHAIN_OF_THOUGHT_BACKGROUND = """
基于以下信息生成场景背景:
- 行业：{industry}
- AI 扮演角色：{ai_role}  ← 改为 ai_role
- 角色描述：{role_description}
- 延展信息：{extended_info}

生成一个{ai_role}在{industry}场景中的背景故事。
"""
```

### 方案 2: 重构设计（更彻底）

**核心思路**: 明确区分"用户侧"和"AI 侧"的数据模型

#### 修改数据模型
**文件**: `agent/service/scene/models.py`

```python
@dataclass
class SceneContent:
    """场景内容数据模型"""
    industry: str
    user_role: str      # 用户扮演的角色（销售、客服等）
    ai_role: str        # AI 扮演的角色（客户、访客等）
    background_info: str
    main_questions: List[MainQuestion]
    trigger_groups: List[TriggerGroup]
    dimensions: List[EvaluationDimension]
    emotion_profile: EmotionProfile
    additional_requirements: str = ""
```

#### 修改提示词结构
生成的提示词应该更明确：

```
# 角色设定
你是一名汽车销售行业的**客户**（AI 扮演）。

# 用户角色
用户将扮演**销售顾问**，与你进行对话练习。

# 场景背景
（客户视角的背景描述）

# 你的任务
作为客户，你需要：
1. 提出关于激光雷达的问题
2. 表达对安全性的担忧
3. 对比竞品车型
...

# 考核维度
（评估 AI 如何扮演客户）
```
