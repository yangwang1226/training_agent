# 按钮始终显示优化说明

## 🎯 优化目标

**用户需求**：
- 让"保存场景"和"开始对练"按钮始终显示
- 不要隐藏按钮
- 用户可以随时点击开始对练

## 🔧 修改内容

### 1. 移除 HTML 中的隐藏样式

**文件**: `front_end/scene/templates/create.html`

**修改前**:
```html
<div class="action-bar" id="action-bar" style="display: none;">
    <div class="action-content">
        <div class="success-message">
            ✅ <span id="success-text">场景内容生成成功！</span>
        </div>
        ...
    </div>
</div>
```

**修改后**:
```html
<div class="action-bar" id="action-bar">
    <div class="action-content">
        <div class="success-message">
            <span id="success-text">💡 随时可以开始对练</span>
        </div>
        ...
    </div>
</div>
```

**改动**:
- ✅ 移除 `style="display: none;"`
- ✅ 修改提示文字为"💡 随时可以开始对练"

### 2. 移除 JavaScript 中的显示逻辑

**文件**: `front_end/scene/static/js/create.js`

**修改前**:
```javascript
if (data.is_ready) {
    showActionBar();
}
```

**修改后**:
```javascript
// ✅ 移除 is_ready 检查，按钮始终显示
// if (data.is_ready) {
//     showActionBar();
// }
```

**改动**:
- ✅ 注释掉 `showActionBar()` 调用
- ✅ 不再检查 `is_ready` 状态

### 3. 移除 showActionBar 函数

**文件**: `front_end/scene/static/js/create.js`

**修改前**:
```javascript
function showActionBar() {
    actionBar.style.display = 'block';
}
```

**修改后**:
```javascript
// ✅ 移除 showActionBar 函数，按钮始终显示
// function showActionBar() {
//     actionBar.style.display = 'block';
// }
```

**改动**:
- ✅ 注释掉整个函数
- ✅ 不再需要动态显示按钮

## 📊 修改文件清单

1. ✅ `front_end/scene/templates/create.html`
   - 移除 `style="display: none;"`
   - 修改提示文字

2. ✅ `front_end/scene/static/js/create.js`

## 📝 技术说明

### 按钮显示机制

**修复前**:
```
后端返回 is_ready=true
  ↓
前端调用 showActionBar()
  ↓
设置 display: block
  ↓
按钮显示
```

**修复后**:
```
HTML 中直接显示
  ↓
无需后端检查
  ↓
无需 JavaScript 控制
  ↓
按钮始终可见
```

### 后端逻辑不变

虽然后端仍然计算 `is_ready`，但前端不再使用这个值：

```python
# 后端仍然返回 is_ready
return {
    "success": True,
    "is_ready": True,  # ← 仍然计算，但前端不用了
    "state": {...}
}
```

**优点**:
- ✅ 向后兼容
- ✅ 不影响其他功能
- ✅ 只是前端不再依赖这个值
