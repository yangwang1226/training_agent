### 核心修改点

#### 1. build_prompt 函数
```python
# 修复前
f"你是一名{content.industry}行业的{content.role_type}。"

# 修复后
ai_character = content.ai_role if hasattr(content, 'ai_role') and content.ai_role else content.role_type
f"你是一名{content.industry}行业的{ai_character}。"
```

#### 2. SceneContent 数据模型
```python
@dataclass
class SceneContent:
    industry: str = ""
    role_type: str = ""
    ai_role: str = ""  # ✅ 新增：AI 扮演的角色
    ...
```

#### 3. 提示词模板
```python

CHAIN_OF_THOUGHT_BACKGROUND = """...为{industry}行业的{ai_role}角色设计..."""
```

## ✅ 验收标准

### 必须满足的条件

1. ✅ 提示词第一句话正确
   - "你是一名{行业}行业的{ai_role}"
   - ai_role 必须是"客户"、"访客"等，而不是"销售"

2. ✅ 场景背景视角正确
   - 从 AI 角色（客户）的视角描述
   - 不是从用户角色（销售）的视角描述

3. ✅ 主问题正确
   - 问题是 AI 角色（客户）会问的
   - 不是用户角色（销售）会问的

4. ✅ 情绪画像正确
   - 描述 AI 角色（客户）的心理状态
   - 不是用户角色（销售）的心理状态

5. ✅ 对练过程正确
   - AI 正确扮演客户，提出问题
   - 用户正确扮演销售，进行回应

### 不允许出现的问题

- ❌ 提示词："你是一名汽车销售行业的销售顾问"
- ❌ 背景描述："销售顾问小张站在展厅..."
- ❌ 主问题："先生，请问您想了解什么车型？"（这是销售的话术）
- ❌ 情绪画像："销售顾问感到紧张..."
