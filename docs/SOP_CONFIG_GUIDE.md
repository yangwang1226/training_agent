# SOP 质检项配置功能使用指南

## 📋 功能概述

SOP（标准操作流程）质检项配置功能允许管理员为不同场景配置标准化的质检清单，用于后续的训练评估。

## 🎯 核心功能

1. **场景选择**：从预设场景列表中选择要配置的场景
2. **质检项管理**：添加、编辑、删除质检项
3. **类型设置**：支持"必须做"和"禁止做"两种类型
4. **关键词配置**：为每个质检项设置判断关键词
5. **分类管理**：对质检项进行分类（如：接待礼仪、需求挖掘等）
6. **一键保存**：将配置保存到数据库

## 🚀 快速开始

### 1. 数据库迁移

首先需要为数据库添加 SOP 字段：

```bash
python scripts/migrate_add_sop_field.py
```

### 2. 启动应用

```bash
python app.py
```

### 3. 访问配置页面

在浏览器中打开：

```
http://localhost:5000/sop/config
```

## 📖 使用步骤

### 步骤 1：选择场景

1. 在页面顶部的下拉框中选择要配置的场景
2. 场景按行业分组显示（汽车销售、教育培训等）
3. 选择后会自动加载该场景已有的 SOP 质检项

### 步骤 2：添加质检项

1. 点击右上角的 **"+ 添加质检项"** 按钮
2. 在弹出的对话框中填写：
   - **质检项名称**（必填）：如 "30秒内问候客户"
   - **类型**（必填）：选择 "✓ 必须做" 或 "✗ 禁止做"
   - **关键词**（可选）：用逗号分隔，如 "你好,欢迎,请问"
   - **分类标签**（可选）：如 "接待礼仪"
   - **描述说明**（可选）：详细说明该质检项的要求
3. 点击 **"确定"** 保存

### 步骤 3：编辑质检项

1. 在质检项列表中找到要编辑的项
2. 点击该项右侧的 **"编辑"** 按钮
3. 在弹出的对话框中修改信息
4. 点击 **"确定"** 保存修改

### 步骤 4：删除质检项

1. 在质检项列表中找到要删除的项
2. 点击该项右侧的 **"删除"** 按钮
3. 在确认对话框中点击 **"确定"**

### 步骤 5：保存配置

1. 完成所有质检项的配置后
2. 点击右上角的 **"💾 保存"** 按钮
3. 等待提示 "✓ 保存成功"

## 📊 质检项数据结构

每个质检项包含以下字段：

```json
{
  "item_id": "SOP001",           // 质检项ID（自动生成）
  "item_name": "30秒内问候客户",  // 质检项名称
  "check_type": "must_do",       // 类型：must_do 或 must_not
  "keywords": ["你好", "欢迎"],   // 关键词列表
  "category": "接待礼仪",         // 分类标签
  "item_desc": "客户进店后..."   // 描述说明
}
```

## 🔧 API 接口说明

### 1. 获取场景的 SOP 清单

```http
GET /api/sop/checklist/{scene_code}
```

**响应示例：**
```json
{
  "success": true,
  "data": {
    "scene_code": "auto_sales_001",
    "checklist": [
      {
        "item_id": "SOP001",
        "item_name": "主动问候客户",
        "check_type": "must_do",
        "keywords": ["你好", "欢迎"],
        "category": "接待礼仪"
      }
    ]
  },
  "message": "获取成功"
}
```

### 2. 更新场景的 SOP 清单

```http
PUT /api/sop/checklist/{scene_code}
Content-Type: application/json

{
  "checklist": [
    {
      "item_id": "SOP001",
      "item_name": "主动问候客户",
      "check_type": "must_do",
      "keywords": ["你好", "欢迎"],
      "category": "接待礼仪"
    }
  ]
}
```

### 3. 验证清单格式

```http
POST /api/sop/checklist/{scene_code}/validate
Content-Type: application/json

{
  "checklist": [...]
}
```

### 4. 获取所有配置了 SOP 的场景

```http
GET /api/sop/scenes
```

## 💡 最佳实践

### 1. 质检项命名

- ✅ 清晰具体："30秒内问候客户"
- ❌ 模糊笼统："问候"

### 2. 关键词设置

- 设置多个相关关键词提高识别准确率
- 包含同义词和常见表达方式
- 例如：问候 → ["你好", "欢迎", "您好", "早上好"]

### 3. 类型选择

- **必须做（must_do）**：用于检查应该执行的行为
  - 示例："询问客户预算"、"留取联系方式"
  
- **禁止做（must_not）**：用于检查不应出现的行为
  - 示例："禁止贬低竞品"、"禁止过度承诺"

### 4. 分类管理

建议按业务流程分类：

- **接待礼仪**：问候、自我介绍等
- **需求挖掘**：询问预算、了解需求等
- **产品介绍**：讲解配置、演示功能等
- **促成转化**：试驾邀约、留取联系方式等
- **禁止行为**：贬低竞品、过度承诺等

## 🐛 故障排除

### 问题 1：页面无法访问

**解决方案：**
1. 确认 Flask 应用正在运行
2. 检查端口 5000 是否被占用
3. 查看控制台错误信息

### 问题 2：保存失败

**可能原因：**
1. 数据库字段未添加 → 运行迁移脚本
2. 数据格式错误 → 检查必填字段
3. 场景不存在 → 确认 scene_code 正确

### 问题 3：关键词不生效

**检查项：**
1. 关键词是否用逗号正确分隔
2. 是否包含空格或特殊字符
3. 保存后是否刷新页面
