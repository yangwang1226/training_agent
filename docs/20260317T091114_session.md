> 
> ### 📊 质检项评分设计原则
> 
> 根据我对代码的分析（`assessment_service.py` 的 `evaluate_sop` 方法），当前系统采用的是**分数累加制**：
> 
> ```python
> # 现有逻辑
> if check_type == 'must_do':
>     default_score = 30
> elif check_type == 'must_not_do':
>     default_score = 30
> else:  # should_do
>     default_score = 15
> ```
> 
> **问题分析：**
> 1. ❌ 所有 `must_do` 项分数相同（30分），不合理
> 2. ❌ 没有考虑质检项的业务重要性差异
> 3. ❌ 质检项数量变化会影响总分计算
> 4. ❌ 用户手动添加质检项时不知道该设置多少分
>

> │  • 系统会自动平衡到100分制                             │

> │  [自定义权重配置] [关闭]                               │
