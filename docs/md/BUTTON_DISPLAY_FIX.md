# 按钮显示逻辑优化说明

## 🎯 问题描述

**用户反馈**：
- 已经收集了很多信息（行业、角色、背景等）
- 但底部仍然不显示"保存场景"和"开始对练"按钮
- 用户期望：只要收集了行业信息就应该显示按钮

## 🔍 当前逻辑分析

### 修复前的逻辑

**文件**: `agent/service/scene/models.py`  
**函数**: `is_ready_for_generation()`

```python
def is_ready_for_generation(self) -> bool:
    """检查是否可以开始生成场景内容"""
    return (
        self.collected_info.get("industry", False) and
        self.collected_info.get("role", False) and
        self.collected_info.get("ai_role", False) and  # 必须确认 AI 角色
        self.extended_info_sufficient
    )
```

**问题**：
- ❌ 需要同时满足 4 个条件才显示按钮
- ❌ 条件太严格，用户需要说很多话
- ❌ 体验不好，用户觉得"卡住了"

### 前端显示逻辑

**文件**: `front_end/scene/static/js/create.js`

```javascript
if (data.is_ready) {
    showActionBar();  // 显示底部操作栏
}
```

**流程**：
```
用户发送消息
  ↓
后端提取信息
  ↓
检查 is_ready_for_generation()
  ↓
如果 is_ready=true → 前端显示按钮
```

## ✅ 优化方案

### 新逻辑：只要收集了行业信息就显示按钮

**文件**: `agent/service/scene/models.py`

```python
def is_ready_for_generation(self) -> bool:
    """检查是否可以开始生成场景内容"""
    # ✅ 修改：只要收集了行业信息就可以生成
    return self.collected_info.get("industry", False)
```

**优点**：
- ✅ 用户体验更好，一句话就显示按钮
- ✅ 更灵活，用户可以随时开始对练
- ✅ 降低门槛，不需要收集所有信息

### 示例场景

#### 场景 1: 用户只说了一句话

**对话**：
```
用户：我想创建一个汽车销售的培训场景
```

**信息提取**：
- industry: "汽车销售" ✅
- role_type: 未收集
- ai_role: 未收集
- extended_info: 空

**修复前**：
```
is_ready = False (需要 4 个条件)
❌ 不显示按钮
```

**修复后**：
```
is_ready = True (只要有 industry)
✅ 显示按钮
```

#### 场景 2: 用户说了多句话

**对话**：
```
用户：我想创建一个汽车销售的培训场景
用户：AI 模拟一个想看车的客户
用户：客户预算 20-30 万
```

**信息提取**：
- industry: "汽车销售" ✅
- role_type: "销售顾问" ✅
- ai_role: "客户" ✅
- extended_info: {"预算": "20-30 万"} ✅

**修复前**：
```
is_ready = True (4 个条件都满足)
✅ 显示按钮
```

**修复后**：
```
is_ready = True (有 industry)
✅ 显示按钮
```
