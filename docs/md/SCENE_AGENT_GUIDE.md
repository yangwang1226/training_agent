# 场景智能体重构 - 使用说明

## 📌 项目概述

本次重构实现了一个全新的场景创建系统，具有以下特点:

1. **去模板化** - 不再依赖预设提示词模板
2. **思维链生成** - 使用智能体思维链能力动态生成场景内容
3. **对话式交互** - 通过自然对话收集场景信息
4. **完整评估闭环** - 对练完成后自动生成评估报告

## 🚀 快速开始

### 1. 启动应用

```bash
python app.py
```

应用将在 `http://localhost:5000` 启动。

### 2. 创建新场景

#### 方式一：通过首页入口
1. 访问 `http://localhost:5000/`
2. 点击 "🚀 创建新场景" 按钮

#### 方式二：直接访问
访问 `http://localhost:5000/scene/create/`

### 3. 对话式创建场景

系统会自动开始对话，例如:

```
AI: 你好！我是场景创建助手。请告诉我你想创建什么行业的培训场景？
    比如"我想创建一个汽车销售的培训场景"。

你: 我想创建一个汽车销售的培训场景

AI: 好的！请问您希望 AI 模拟什么角色呢？
    比如"客户"、"销售经理"等。

你: 模拟一个想看车的客户

AI: 明白了。请问这个客户有什么特点吗？
    比如预算、关注的车型、购车需求等。

... (继续对话收集信息)

AI: 场景内容已生成完成！包括背景信息、问题列表、关联问题和考核维度。
    可以点击「开始生成」按钮保存场景并开始对练。
```

### 4. 查看生成的内容

点击 "查看生成的内容" 按钮，可以看到:

- **场景背景**: 详细的场景设定和背景信息
- **主问题列表**: AI 模拟角色会提出的核心问题 (3-5 个)
- **关联问题分组**: 基于触发关键词的问题分组
- **考核维度**: 3-4 个关键能力评估维度
- **情绪画像**: AI 角色的情绪状态和沟通风格

### 5. 开始对练

点击 "保存并开始对练" 按钮，系统会:

1. 保存场景到数据库
2. 自动跳转到实时对练页面
3. 使用 qwen-omni realtime 模型进行语音对话

### 6. 查看评估报告

对练完成后，系统会自动:

1. 保存音频录音
2. 保存对话转录文字
3. 调用 qwen-plus-3.5 生成评估报告
4. 将报告保存到数据库

评估报告包括:
- 综合得分
- 各维度得分和反馈
- 亮点和改进建议
- 关键时刻分析
- 金句摘录

```

    "success": true,
    "response": "好的，请问...",
    "options": [],
    "is_ready": false,
    "state": {...}

```

Response: {
    "success": true,
    "scene_id": 123,
    "scene_name": "汽车销售_客户_场景",
    "redirect_url": "/realtime/123",

```
GET /api/scene/status
Response: {
    "success": true,
    "state": {
        "industry": "汽车",
        "role_type": "客户",
        "collected_info": {...},
        "is_ready": true

```

#### 5. 重置
```
POST /api/scene/reset
Response: {
    "success": true,
    "message": "场景智能体已重置"
}
```

## 📊 数据库表结构

### ai_coach_scene 表

新增字段:
- `dimension_config` - 维度配置 JSON
- `role_type` - AI 模拟角色类型
- `role_description` - 角色描述
- `industry` - 行业
- `training_goal` - 培训目标
- `full_evaluation_prompt` - 完整评估提示词

### ai_coach_record 表

评估报告保存到:
- `ai_evaluate` - AI 评估结果 (JSON 格式)
- `ai_advise` - AI 建议摘要
- `score` - 综合得分
- `word_content` - 对话内容 JSON
- `oss_file_path` - 音频文件路径
- `call_duration` - 通话时长

## 💡 使用技巧

### 1. 提供详细信息
在对话中提供越多的背景信息，生成的场景质量越高。例如:

**好**: "我想创建一个汽车销售场景，客户预算 20 万，关注 SUV，主要是家庭使用。"

**差**: "我想创建一个汽车销售场景。"

### 2. 明确角色特点
描述 AI 模拟角色的特点:

- 性格特点 (温和、挑剔、犹豫等)
- 关注重点 (价格、性能、外观等)
- 决策风格 (理性、感性、从众等)

### 3. 调整考核维度
如果对生成的考核维度不满意，可以:
- 在对话中提出调整要求
- 手动修改数据库中的维度配置

### 4. 查看评估报告
对练完成后可在评估页面查看详细报告:
- 访问 `http://localhost:5000/evaluate/`
- 查看用户能力画像
- 查看训练历史
- 查看改进建议

## 🔍 故障排查

### 问题 1: 场景无法生成
**症状**: 点击"开始生成"后无响应

**解决方案**:
1. 检查浏览器控制台是否有错误
2. 检查后端日志
3. 确认信息已收集完成 (状态面板全绿)

### 问题 2: 评估报告未生成
**症状**: 对练完成后没有评估报告

**解决方案**:
1. 检查 Qwen API 密钥配置
2. 查看后端日志中的错误信息
3. 确认数据库连接正常

### 问题 3: 音频未保存
**症状**: 对练完成后找不到音频文件

**解决方案**:
1. 检查 `audio_file/` 目录权限
2. 确认 WebSocket 连接正常
3. 检查浏览器麦克风权限
