🧪 SOP 前端缓存流程测试

测试场景

1. 用户选择预设场景
2. 打开背景补充弹窗
3. 配置 SOP 质检项（添加/删除）
4. 保存质检项（暂存到前端）
5. 点击"开始训练"生成场景
6. 场景生成后自动保存质检项到服务器

关键代码验证

1. 暂存质检项（前端缓存）

// sop_config_inline.js
let pendingSopItems = null;

function saveSopItems() {
    // 不调用 API，只保存到内存
    pendingSopItems = validItems.map(...);
    showToast('已暂存 N 项质检项，生成场景时将自动保存');
    updateSopPreviewInBackgroundModal(validItems);
}

2. 场景生成后自动保存

// industry.js
async function submitWithBackground(backgroundHint) {
    const data = await fetch('/api/preset-scene/generate-from-preset', {...});
    
    if (data.success) {
        const sceneId = data.scene_id;
        
        // 如果有缓存的质检项，自动保存
        if (pendingSopItems && pendingSopItems.length > 0) {
            await saveSopItemsToServer(sceneId, pendingSopItems);
            pendingSopItems = null; // 清空缓存
        }
        
        window.location.href = data.redirect_url;
    }
}

3. 重新打开配置时加载缓存

// sop_config_inline.js
function openSopConfigModal() {
    // 优先加载缓存的质检项
    if (pendingSopItems && pendingSopItems.length > 0) {
        currentSopItems = pendingSopItems.map(...);
        renderSopItems();
    } else {
        loadExistingSopItems(); // 从服务器加载
    }
}

手动测试步骤

  1. 启动服务器: python app.py
  2. 访问: http://localhost:5000/industry/
  3. 选择任意预设场景（如：汽车销售）
  4. 在背景补充弹窗中展开 "SOP 质检项设置"
  5. 点击 "配置质检项"
  6. 添加一些质检项（如："主动问候客户"）
  7. 点击 "保存质检项"
  8. 观察提示："已暂存 N 项质检项，生成场景时将自动保存"
  9. 返回背景补充弹窗，查看 SOP 预览区域是否更新
  10. 点击 "开始训练"
  11. 观察提示："正在保存质检项..." → "质检项保存成功！"
  12. 进入对练页面后，可以在数据库中验证质检项是否保存
